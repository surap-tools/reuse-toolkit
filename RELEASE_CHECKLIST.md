# Release Checklist

Diese Checkliste muss vor jeder öffentlichen Veröffentlichung geprüft werden.

## Repository

- [ ] `README.md` ist vollständig.
- [ ] `LICENSE` ist vorhanden.
- [ ] Lizenz ist im README genannt.
- [ ] Keine internen Notizen, privaten Daten oder Zugangsdaten im Repository.
- [ ] Keine ZIP-Dateien, Rohdaten oder temporären Arbeitsdateien im Repository.
- [ ] Repository-Beschreibung und Topics sind gesetzt.

## Tool

- [ ] Tool startet lokal ohne Build-Schritt.
- [ ] Hauptdatei heißt `index.html`, falls GitHub Pages genutzt wird.
- [ ] Keine externen Dependencies hinzugefügt.
- [ ] Keine Analytics, Cookies, Tracker oder externen Fonts.
- [ ] Impressum und Datenschutz sind verlinkt, falls das Tool öffentlich bereitgestellt wird.
- [ ] Footer enthält klare Quellen- und Haftungshinweise, falls relevant.

## Daten

- [ ] Alle Demo-Daten sind klar als Demo-Daten markiert.
- [ ] Keine unverifizierten Daten werden als geprüfte ÖKOBAUDAT-Daten dargestellt.
- [ ] ÖKOBAUDAT-Version ist genannt, sobald echte ÖKOBAUDAT-Daten genutzt werden.
- [ ] Interne SURAP-Korrekturen, SQL-Overrides oder kuratierte Daten wurden nicht ungeprüft veröffentlicht.
- [ ] Datenlizenz und Quellenhinweise sind geprüft.

## Methodik

- [ ] Berechnungsannahmen sind im README erklärt.
- [ ] Grenzen des Tools sind beschrieben.
- [ ] Tool wird nicht als vollständige Gebäudeökobilanz dargestellt, wenn es das nicht ist.
- [ ] Datenquellen, Versionen und methodische Annahmen sind klar dokumentiert.

## Veröffentlichung

- [ ] GitHub Pages funktioniert.
- [ ] Öffentlicher Link ist im README eingetragen.
- [ ] Demo-/Beta-Status ist sichtbar.
- [ ] Erste öffentliche Kommunikation ist vorbereitet.
